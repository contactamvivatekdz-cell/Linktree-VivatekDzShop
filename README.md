## Publication sur GitHub Pages

1. Créez un dépôt GitHub (par exemple `vivatek-dz-link`), puis téléversez le contenu de ce dossier à la racine.
2. Ouvrez **Settings → Pages**.
3. Dans **Build and deployment**, choisissez **Deploy from a branch**.
4. Sélectionnez `main` et `/ (root)`, puis enregistrez.
5. Utilisez l'adresse publiée par GitHub Pages dans la bio de vos réseaux sociaux.

Le site est statique : aucun serveur, aucune base de données et aucune collecte de données ne sont nécessaires.
